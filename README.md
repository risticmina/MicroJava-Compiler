# MicroJava Compiler

A MicroJava compiler implemented in Java as part of the **Programming Translators 1** course at the University of Belgrade, School of Electrical Engineering.

The compiler performs the following phases:

- **Lexical analysis** – recognizes tokens using JFlex.
- **Syntax analysis** – parses the source code using Java CUP and builds an abstract syntax tree.
- **Semantic analysis** – performs semantic checks and manages symbol information.
- **Code generation** – generates MicroJava bytecode (`.obj`).

## Technologies

- Java
- JFlex
- Java CUP
- MicroJava Virtual Machine
- Apache Ant

## Project Structure

```text
MJCompiler/
├── config/       # Configuration files
├── lib/          # Required libraries
├── spec/         # JFlex and CUP specifications
├── src/          # Compiler source code and generated classes
├── test/         # Test programs and input data
├── build.xml     # Apache Ant build configuration
└── MJProjekat.docx
```

## Running the Compiler

1. Import the project into Eclipse as an existing Java project.
2. Make sure the project uses JDK 8.
3. Run `Compiler.java` to compile the MicroJava source program.
4. The compiler reads `test/program.mj` and generates the output bytecode file `test/program.obj`.
5. Use the `runObj` target from `build.xml` to execute the generated bytecode in the MicroJava Virtual Machine.
